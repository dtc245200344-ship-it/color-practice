# Newsletter Color Practice

Bài tập phối màu newsletter theo yêu cầu CodeGym.

## Nội dung
- `newsletter_version1.html`: phiên bản 1, palette xanh dương - xanh ngọc.
- `newsletter_version2.html`: phiên bản 2, palette tím - hồng - vàng.
- Cả hai phiên bản dùng Bootstrap 5.3.3 và responsive trên desktop/tablet/mobile.

## Palette
### Version 1
- Primary: #2563EB
- Secondary: #0EA5E9
- Accent: #14B8A6
- Dark: #0F172A
- Light background: #EFF6FF

### Version 2
- Primary: #7C3AED
- Secondary: #DB2777
- Accent: #F59E0B
- Dark: #2E1065
- Light background: #FFF7ED

## Nguyên tắc áp dụng
- Màu chủ đạo dùng cho header, tiêu đề và CTA.
- Màu phụ dùng cho các khối nội dung.
- Màu accent tạo điểm nhấn.
- Nền sáng và màu chữ đậm để tăng khả năng đọc.
- Bootstrap grid giúp bố cục tự co giãn trên các kích thước màn hình.

Bài yêu cầu hoàn thành 2 phiên bản với 2 bộ màu khác nhau, mã nguồn HTML/CSS hoạt động đúng và đưa lên GitHub/CodePen.
